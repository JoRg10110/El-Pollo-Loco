# El Pollo Loco - A 2D JavaScript Game

A fast-paced, side-scrolling 2D arcade game built entirely with Object-Oriented JavaScript, HTML5 Canvas, and CSS3. Help Pepe defend the Wild West against angry chickens and defeat the ultimate Endboss!

## 🚀 Features
* **Custom Physics Engine:** Implements smooth running, jumping, and gravity systems.
* **Smart UI Layouts:** Optimized for multiple platforms with a responsive design separating Desktop controls, Mobile viewports, and custom Large Tablet HUD alignments.
* **Dynamic Enemy AI:** Multi-tiered enemy waves featuring standard chickens, small chickens with fast pacing, and an aggressive state-driven Endboss that rushes the player.
* **Combat Mechanics:** Jump on top of regular enemies to defeat them or use collectible bottles with a 1-second throwing cooldown for ranged attacks.

---

## 🛠️ Tech Stack
* **Language:** JavaScript (ES6+, Object-Oriented)
* **Rendering:** HTML5 Canvas API
* **Styling:** CSS3 (Media Queries, Flexbox)
* **Documentation:** Standard JS-Doc notation

---

## 🕹️ Controls

### Desktop
* `Arrow Left` / `Arrow Right` - Move Pepe left or right
* `Space` / `Arrow Up` - Jump
* `D` - Throw Bottle (1-second cooldown)
* `B` - Toggle Debug Boundaries

### Mobile & Tablet
* On-screen touch buttons automatically scale and align dynamically based on device aspect ratio.
